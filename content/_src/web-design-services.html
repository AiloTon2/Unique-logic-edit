SEO／GEO 架構先行：

每頁的 H1、title 及 Schema 按關鍵字規劃好，Google 及 AI 都讀得懂。

改版不丟排名：

上線前做舊網址對照表及 301 轉址，上線後監察 Search Console。

頁數、語言、功能、修改次數、保用期及第二年費用，簽約前寫清楚。

域名、原始碼、後台全部以你公司名義。

GA4、表格、WhatsApp 及來電查詢由第一天開始記錄。

多語言一次做好：

繁中、簡中、英文架構及 hreflang，每個語言有自己的關鍵字。

服務內容

企業網站：

  • 首頁、關於我們、服務頁、案例、聯絡頁；每頁按一個主要關鍵字及查詢目的設計。

WordPress 網站：

  • 自訂主題，後台易於更新內容；外掛數量控制，減少安全及速度問題。

客製前端開發（React／Next.js）：

  • 適合需要高速、複雜功能或系統串接的網站，可配合無頭 CMS。

多語言網站：

  • 繁中、簡中、英文，獨立網址結構及 hreflang，不靠自動翻譯外掛。

網站改版及搬遷：

  • 舊網址對照、301 轉址、內容搬遷、Search Console 監察。

速度優化（Core Web Vitals）：

  • 圖片壓縮、延遲載入、快取設定，以 Google「良好」標準為目標。

無障礙設計：

  • 色彩對比、字體大小、鍵盤操作、圖片替代文字，以 WCAG 2.2 AA 為目標。

追蹤及表格：

  • GA4、Google 代碼管理工具、表格、WhatsApp 及電話點擊事件。

常見問題

選擇網頁設計公司時，可比較網站策略、設計及網頁開發能力、手機體驗、CMS、SEO 基礎、維護方式、時程和交付範圍，不應只以首頁視覺或報價判斷。

公司網站設計應在架構、內容層級、速度、手機體驗和可抓取性方面預留 SEO 基礎；正式 SEO 網站優化則可在上線後按資料和搜尋意圖持續改善。

網頁製作公司可按需要處理 WordPress 內容管理、版面、功能、表單和更新流程；實際維護、主機及第三方工具責任應在項目開始前確認。

響應式網頁會按裝置尺寸調整內容和互動方式，讓手機、平板及桌面使用者都能完成瀏覽和查詢；仍需以實機測試速度、表單和主要轉換流程。

部分網頁設計公司可把網頁、SEO、內容或廣告結合，但服務範圍和成效指標應分開列明，避免把網站製作交付與後續推廣結果混為一談。
